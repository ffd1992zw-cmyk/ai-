1. 下载本文件夹的 `index.html`。
2. 在 https://github.com/ffd1992zw-cmyk/ai-/upload/main 上传这个同名文件，确认覆盖 `main` 分支根目录下的 `index.html` 并提交。
3. GitHub Pages 原有 `main / (root)` 设置无需变更，`.nojekyll` 已有时无需重复上传。
4. 访问 https://ffd1992zw-cmyk.github.io/ai-/ ，强制刷新浏览器查看新版。

本次通过 ChatGPT GitHub 连接写入文件时仍返回 403，因此线上站点不会因本次生成文件而自动变更，只有 GitHub 仓库提交后才会上线新版。

## 更新边界

- GitHub 公开目录是网络按需扫描，不是后台定时收集服务。匿名接口可能限流。
- 每周 AI Skills 情报任务已更新七大偏好，但目前不会自动写入网页本地数据库。
- 本站是静态网站，收藏及偏好只保存在当前浏览器；更换设备/浏览器请使用 JSON 备份迁移。
- 评分为**基于已收录信息的匹配初筛**，不构成安全检测、可用性或产品性能认证。
